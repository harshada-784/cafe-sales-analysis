# Raw Dataset

The original raw dataset used for this project is not redistributed in this repository.

## Dataset Information

- Dataset Name: Coffee Sales Dataset
- Original Source: Kaggle
- Dataset Author: Navjot Kaushal
- Analysis Period: March 2024 – March 2025
- Transactions Used: 3,547
- Products: 8
- Format: CSV

## Source

The original dataset is available on Kaggle:

https://www.kaggle.com/datasets/navjotkaushal/coffee-sales-dataset

## Data Preparation

The source dataset was reviewed and prepared before analysis. Additional analytical fields such as time of day, weekday, month, weekday sort order, month sort order, and hour of day were prepared for the analysis.

The cleaned dataset used in this project is available in the `cleaned_data/` folder.

The original source CSV is not redistributed in this repository. Please refer to the original Kaggle dataset for the source data.
